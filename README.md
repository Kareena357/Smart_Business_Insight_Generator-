# Smart_Business_Insight_Generator-
AI -powered business analytics dashboard built with Streamlit , Pandas, SQL, Excel and gemini AI for generating smart business insights, KPI analysis, Interactive Charts, and downloadable reports.
Features :
1. Upload Excel or CSV datasets
2. Analyze revenue, profit,cost,products,and regions
3. Generate AI-Powered business insights and recommendations
4. Interactive KPI dashboard
5. Dynamic sidebar filters
6. Interactive charts and visualizations
7. Download AI reports and filtered datasets
8. Secure login page
Technologies Used:
1. Python
2. Streamlit
3. Pandas
4. Gemini AI
5. Matplotlib
Installation
Install required libraries:
pip install -r requirements.txt
Run the applicaton:
streamlit run app.py
